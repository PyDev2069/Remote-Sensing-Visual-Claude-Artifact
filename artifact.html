NDMI tracks canopy moisture. It gets its own counterfactual, built the same way as NDVI.

P0Standard cloud mask + seasonal fit. Tides and shifting cloud gaps leak into the answer.
P1P0 + fixed pre-Amphan mangrove footprint and valid-pixel checks, so the same ground is measured every date.
P2P1 + water proxy from creek and mudflat patches. Only compare dates whose water level was seen before Amphan.
P3P2 + swap in different reference patches, to check the result does not depend on one choice.

Bars = prediction error and false departures (shorter is better). This is the pattern the study will test, not a measured result. P2 counts as essential only if it improves predictions without hiding real canopy-to-water loss.

  1. Learn from clean pre-Amphan dates: index = trend + two seasonal waves + water proxy, fitted with Ridge regression.
  2. Predict forward: the expected index without Amphan, plus a prediction band checked on held-out time blocks.
  3. Compare on dates with comparable water: deficit D = expected minus observed.
  4. Classify: inside the band is normal. Below it on 3+ clear dates over 45+ days is persistent. Back inside for a set time is sustained return.
D = Expected - Observed

P0 to P3 only change the data going into step 1. The model stays the same, so any gain comes from preprocessing.
